## ✨ Key Features & Architecture

* **🎮 3D WebGL Neo-Mythic Citadel Vista**:
  * Real-time Three.js scene featuring floating chrono-core with orbital rune rings, cruising sci-fi starships, volumetric horizon mist, and dynamic stardust.
* **🪐 Unified Visual Continuity**:
  * Seamless atmospheric background across all sectors (Events, Workshops, Radar Map, Schedule, Hospitality, Sponsors, and Footer) matching the main Citadel theme.
* **⚡ Overclock 4.8 GHz Mode**:
  * Dynamic global theme shift to ultraviolet chromatic overdrive with audio feedback and reactive color grading.
* **🎯 Interactive Stardust Rocket Reticle**:
  * Custom smooth rocket cursor with subtle high-tech sparks and lock-on targeting brackets.
* **🔊 Cyber Sound FX Synthesizer**:
  * Custom Web Audio API sound engine providing immersive hover, click, and ambient audio feedback.
* **🗺️ Geo-Spatial Radar Telemetry Map**:
  * Interactive holographic blueprint map of festival sectors with real-time sector radar sweep.
* **🏆 Interactive Event Hub & Masterclasses**:
  * Comprehensive event modals with rulebooks, round formats, eligibility criteria, and instant delegate registration flow.

## 🚀 Local Development Setup

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/ishanarora0901/Aetheria-project.git

# 2. Navigate to project directory
cd Aetheria-project

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:3000` (or the port shown in terminal) to view the application.

---

## 🚢 Deploying to Vercel

1. Go to **[vercel.com](https://vercel.com)** and sign in with GitHub.
2. Click **"Add New..."** → **"Project"**.
3. Select **`Aetheria-project`** from your GitHub repositories list.
4. Keep the default settings (Framework Preset: **Vite**, Root Directory: **`./`**).
5. Click **"Deploy"**. Your site will be live within 60 seconds!
